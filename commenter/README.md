# Коментатор (commenter)

Шар коментарів, який малює піни на макеті, форму нового коментаря й рядок режимів і працює з обома каналами (локальним і
командним) через сховище, яке йому дає адаптер модуля `comments`. Один вихідний файл — `src/comment-layer.js`, збірка — мінімізований
`comment-layer.min.js` у `app/vendor/`.

## Звідки

Джерело — comment-layer зі старого репозиторію дизайн-офісу, коміт `3581cd0`; перенесене сюди 13.11.2026. Копія в тому репозиторії живе
окремо й далі не синхронізується: **для Deai ця тека — головне джерело**.

## Режим хоста

Без опції `host` коментатор працює як завжди: своя ручка на краю, своя панель, свої клавіші (так він працює в опублікованих
превʼю й у чужих проєктах). З `host` оболонка бере панель на себе:

```js
init({ host: {
  onReady(),            // коментатор готовий
  onChange(snapshot),   // змінився список / стан; snapshot — мілка копія
  onSelect(id),         // користувач вибрав пін
  onMode(on),           // режим коментування увімкнено / вимкнено
  rightInset(),         // скільки пікселів праворуч займає панель оболонки
}})
```

Методи для оболонки: `snapshot()`, `focus(id)`, `carry(id)` (перенести коментар у поточну ітерацію), `editComment(id, text)`,
`openShot(id)`, `togglePins()`; а також наявні `setCommentMode(on)`, `resolveComment(id)`, `reopenComment(id)`, `removeComment(id)`.

У режимі хоста: ручка й панель коментатора сховані; на клавіатуру він слухає лише Escape у власному вікні; ігнорує клавіші з полів
поза своїм shadow root; `destroy()` не викликає жодних колбеків (тож панель оболонки не закривається при зміні каналу).

## Збірка й штамп

```bash
cd commenter && npm ci && npm run build
```

Збірка пише прямо в `app/vendor/` і в `commenter/build-stamp.json` (хеш джерела, версія esbuild, хеші виходів). Вихід
детермінований: повторна збірка не дає різниці в `git diff`.

## Охоронець

`tests/commenter-stamp.test.mjs` падає, якщо джерело й зібраний файл розійшлися зі штампом — тобто джерело змінили без перезбирання.
Тести самого коментатора: `node --test commenter/test/*.test.mjs`.
