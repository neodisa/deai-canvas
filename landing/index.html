Northline · Brief to the agent

“Design a train booking flow for desktop and mobile. Include a state for dates with no departures.”

  1. 01

    Give your agent a brief

    Start a blank task or import an existing HTML prototype. Your agent builds the first pass in the workspace folder.

  2. 02

    Open it in Deai Canvas

    Open the live booking page, check it at phone width, then zoom out to see the entire flow and its edge states.

  3. 03

    Point to the change

    Pin a note to the departure field. Your agent reads the pin, updates the page in a new iteration, and can leave a note explaining the fix.

  4. 04

    Share the right pass

    Keep earlier iterations editable. Mark the one you want reviewed and publish a clickable preview for your team.

Make Deai Canvas fit
your workflow.

Set up a space once, then open it to pick up your work. Screens, iterations, the Inspector and local pins are built in. A module connects one part of the workflow to a tool you choose.

Publishing
Export a static preview to a folder from day one. Connect Vercel to publish a shareable preview on your own account.
Design system
Connect a CSS tokens file so the Inspector can flag values that fall outside your design system.
Team review
Use Supabase for shared comments and a team dashboard. Turn on Microsoft Teams notifications for new comments.
Project tools
Sync editable iterations to your own git repo and show Jira issue status alongside tasks in Deai Canvas.

Choose or swap providers in each space’s Settings. Use the built-in modules or add one for your team’s own service.

Good to know.

How do I start a project?

Open an existing space folder or create a space for a client or project. Start from an empty task, import an HTML folder, or have your agent build the first iteration. Your tasks stay together in the space, with search, tags and tabs for open work.

Can I bring the prototype into Figma?

Use To Figma to copy the live mockup and paste it into Figma. In Deai Canvas, select a live element to inspect its properties, measure distances and prepare precise edits for your agent.

Where does my work live?

Prototypes, iterations, local comments and snapshots are files on your computer. You choose where to publish previews and which integrations to connect.

Can my team review without installing Deai Canvas?

Yes. Publish a preview to a web host and send your team the URL. They can open it in a browser and, with a team comments module configured, leave feedback there.

What do I need to run it?

Python 3.9 or later and Chrome or Edge. Overview snapshots also use Node.js 20+ and Playwright. Deai Canvas is made for macOS: the launcher, app icon and autostart. On Windows and Linux, run app/serve.py with Python 3.9+ and open it in Chrome or Edge as an app window. A one-command start on every OS is on the roadmap.
