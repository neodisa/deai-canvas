# Модулі 2а — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** каркас вбудованих модулів (роль → постачальник у просторі), модуль `static-publish` (публікація в теку поза простором + локальна роздача в пісочниці) і `css-tokens` (токени ДС з CSS для інспектора).

**Architecture:** новий `app/deai_modules.py` — маніфести, завантаження `exec`-ом, налаштування в `space.json`, секрети в `~/.deai/secrets.json`, вибір постачальника ролі, `capabilities`. `serve.py` кличе ролі через нього; збірка превʼю виноситься в одну функцію `build_preview` для шляху ЛІГА й модулів. UI перемикає зону публікації з `integrations` на `capabilities.publish`.

**Tech Stack:** Python 3 stdlib (`serve.py`, unittest), ES-модулі без збирача, `node:test`, Playwright.

Спека: `docs/superpowers/specs/2026-10-14-modules-2a-design.md` (ревізія 2). Напрям: `docs/design/spaces-and-modules.md`.
