# Етап 4d-3c «Міграція ЛІГИ: `publish`» — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** на першому старті 0.19 простір ЛІГА третім незалежним кроком `liga-4d3c` (свій датований бекап, позначка, відкат; усе або нічого) дістає явний модуль `vercel-publish` у `space.json` (без секретів) із `compat: "design-canvas"`; публікація, пароль превʼю (`1100`/задачі/кореня), проєкти `pv-…`, скоуп, URL і побічні дії для людини ті самі. «ЛІГА» читається з ОДНОГО предиката `deai_modules.publish_legacy_path`; гілка `Handler._publish` для ЛІГИ не змінюється, а лише перемикається предикатом.
