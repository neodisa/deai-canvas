**Goal:** на першому старті 0.18 простір ЛІГА другим незалежним кроком `liga-4d3b` (свій датований бекап, позначка, відкат; усе або нічого) дістає явні модулі `supabase-comments` і `git-sync` у `space.json` + ключ Supabase для коментарів у `secrets.json`; поведінка для людини та сама (канали `comment_project`/`dc/<задача>`, плоскі дзеркала `.mirrors`, тексти «design-canvas»/«GitLab», форма «Нова задача» без поля «Репозиторій»). 1. **«Тести 4d-3a зелені без правок» не виконується буквально для `startup()` і CLI.** Стенд `_Stand` (`tests/test_liga_migrate.py:586`) має Supabase-конфіг, тож `startup()`/CLI `run` на двох кроках дали б другий бекап і другий звіт: падають `StartupTest.test_isolated_with_seam_and_temp_home_runs` і `test_home_only_overridden_deai_home_unset_production_runs` (`len(backups) == 1`), `test_partial_migration_names_unmigrated_roles_with_codes` (`last['skipped']` стає звітом 4d-3b), `RunTest.test_cli_status_dry_run_run` (`dry-run == report(plan())`). Рішення: `plan/run/_run/restore/_restore/status` БЕЗ аргументу `step` лишаються кроком 4d-3a (тести `AfterMigrationParity` викликають `lm.run()` і чекають лише 3a); нове — `run_all()`, `startup()` і CLI ітерують `STEPS`; **єдина правка 4d-3a-тестів** — один рядок у `_Stand.setUp`: `mock.patch.object(liga_migrate, 'STEPS', liga_migrate.ALL_STEPS[:1])` (стенд 4d-3a бачить лише свій крок). Нові тести — у НОВОМУ файлі `tests/test_liga_migrate_b.py` (імпортує `_WriteStand`; патч `STEPS` там знімається).
2. **`compat_of(space, module_id)`** у спеці «читає розв'язані налаштування через `resolve_settings`» — це вимагало б каталогу. Читаємо сирий запис `space_modules(space)[id]['settings']['compat']` (лише `str`, інакше `""`): результат ідентичний, бо рівність перевіряється лише з двома дозволеними значеннями, а недозволене значення `resolve_settings` усе одно відкидає (`bad-settings`) у `module_ctx`; функція лишається ТОТАЛЬНОЮ без обходу каталогу.
3. **Захист за id.** Вбудовані `supabase-dashboard`/`supabase-teams` мають СВОЄ `compat` (`comment-layer`, інший зміст). Тому предикати кажуть «вбудований І `id == 'supabase-comments'`» (канал) та «вбудований І `id == 'git-sync'`» (тексти) — а не просто «вбудований». Спека формулює лише «вбудований».
