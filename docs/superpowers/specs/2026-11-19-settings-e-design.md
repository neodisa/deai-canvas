# Етап Е — «Налаштування» й AGENTS.md (0.31.0)

Статус: погоджено власником 19.11.2026 («давай») за прототипом https://claude.ai/artifact/RfC5kh614NqWqsAvm8DEz5.
Рішення власника: світла тема — НЕ в 0.31 (окремим випуском); AGENTS.md — англійською.
Рівень строгості: середній (звичайна фіча; один фінальний ревʼюер) + живі тести на кожен новий шлях.

## Навіщо

Сторінка «Налаштування» (у коді `conn`, `enterConnections`) — одна довга стрічка секцій по ролях, у кожній картці по 3 кнопки.
Фідбек 12.11: «В Figma» — теж модуль, його треба вмикати/вимикати; свої модулі кожному + інструкція всередині канваса,
що переживає оновлення; кольорова схема застосунку разом із простором. Спека редизайну (етап Е) додає AGENTS.md і групу
«Застосунок» (оновлення, окреме вікно, гарячі клавіші).

## Що робимо

### 1. Каркас сторінки

- `homePage === 'conn'` лишається тим самим оверлеєм `#tasks-home`; усередині — ліва навігація (224 px) + вміст.
- Навігація, дві групи:
  - «Простір · {імʼя}» (крапка кольору простору): **Простір** · **Модулі** · **AGENTS.md**.
  - «Застосунок»: **Загальне** · **Оновлення** · **Гарячі клавіші**.
- Лічильник біля «Модулі» — кількість своїх модулів, що чекають довіри (бурштин); крапка біля «AGENTS.md» — шаблон новіший за файл.
- Поточний розділ — `connSec` (`space|mods|agents|app|upd|keys`), памʼятається в `localStorage` (як `homeUi`), типово `mods`.
- Входи: шестерня (останній розділ), ⌘K «Налаштування простору «X»» і «Налаштування…» з фішки простору → `mods`;
  `enterConnections('vcs')` (glsetup) → `mods` з фокусом на картці ролі (порожня роль — пунктирна картка).
- Вузька ширина (< 760 px): навігація — горизонтальний рядок над вмістом.
- Esc на сторінці — як зараз (вихід рівнем вище).
- Заголовок смуги лишається «Налаштування».

### 2. Модулі

- Заголовок «Модулі» + кнопка «Додати модуль» праворуч.
- Сітка карток (`auto-fill, minmax(250px,1fr)`), у порядку `ROLE_ORDER`. Картка: іконка ролі (свій модуль — `puzzle`),
  назва (+ тег «свій»), роль, стан (крапка + слово), **одна дія за станом**, «⋯» з рештою.
- Що в сітці: увімкнені модулі (вбудовані й свої), свої модулі з теки простору (навіть невімкнені), «Не встановлено».
  Вимкнені вбудовані — лише в каталозі.
- Стан → дія на картці (решта — у «⋯»):

  | стан | слово | дія на картці |
  |---|---|---|
  | перевірено, ок | Підключено | — |
  | не перевірено | Не перевірено | Перевірити |
  | помилка | Помилка (+ рядок причини червоним) | Налаштувати |
  | свій, потрібна довіра | Чекає довіри (замок) | Довірити |
  | свій, довірений, не ввімкнений | Вимкнено | Підключити |
  | не встановлено на цьому компʼютері | Не встановлено | — |
  | свій, довіритись не можна | Довіритись не можна | Чому? (наявне `trustinfo`) |

- «⋯»: Налаштувати (є налаштування) · Перевірити (увімкнений) · Код (свій) · Забрати довіру (свій довірений) · — · Вимкнути
  (увімкнений; червоним).
- Клік по картці: увімкнений → шухляда налаштувань (наявна `cnDrawer`, без змін); потрібна довіра → діалог довіри.
- **Вимкнути** — питання В КАРТЦІ (як видалення задачі етапу Д, клас `.cfm`): «Вимкнути «X»? {наслідок}» з наявних
  `cnDisableAsk`/`cnDisableNone`; фокус на «Скасувати»; Esc — скасувати. Діалог `cnDisableAsk` для картки більше не потрібен.
- **Ролі без модуля** — під сіткою блок «Без модуля · N»: пунктирні картки (іконка ролі, назва ролі, наслідок з наявних
  рядків `none`, кнопка «Додати» → каталог з підсвіченою роллю). Роль «Інше» не має порожньої картки.
- **«В Figma»** — картка в ролі «Інструменти» (іконка `figma`), стан «Увімкнено»/«Вимкнено», «⋯ → Вимкнути» /
  «Увімкнути» на картці. Без шухляди (налаштувань нема). Вимкнено → кнопки «В Figma» нема в смузі й у ⌘K. Порожньої
  картки для «Інструментів» нема: вимкнений «В Figma» лишається в сітці зі станом «Вимкнено».
  Зберігається в `space.json` простору: `"tools": {"figma": false}` (відсутній ключ = увімкнено). Не модуль із
  `server.py`: неявних модулів після 4d-4c нема, і справжній модуль зник би в усіх наявних просторах.
- Блок «Через агента» (API модулів) зі сторінки прибираємо — він переїжджає в AGENTS.md (розділ 4).
- Тексти довіри: «Довіритись…» → «Довірити»; бейдж «Потрібна довіра» → «Чекає довіри». Сам діалог довіри (`trustDialogHTML`,
  системне вікно) — без змін, крім кнопки «Довіряю» → «Довірити».

### 3. Каталог «Додати модуль» і «Свій модуль»

- Діалог (підкладка + картка, система етапу В): «Додати модуль», групи за ролями — вбудовані модулі, яких нема в сітці;
  рядок: іконка, назва, опис (наявний `BUILTIN_TEXT`), кнопка «Підключити» або «Замінити {поточний}» (роль зайнята).
- Вибір → діалог закривається → наявна шухляда в режимі «Підключити» (модуль без налаштувань — вмикається одразу,
  тост «Підключено: X»). «Замінити» не питає вдруге: назва кнопки і є підтвердження; заміна вимикає попередній
  (налаштування лишаються — як `cnReplaceAsk` зараз).
- Останній рядок — пунктирний «Свій модуль» → «Як додати ›» → друга сторінка діалогу (кнопка «‹» назад):
  1. «Попросіть агента» — запит нижче; 2. «Модуль зʼявиться тут» з позначкою «Чекає довіри»; 3. «Перегляньте код і
  довірте» — підтвердите в системному вікні. (Нумерація — справжня послідовність.)
  Поле «Що має робити модуль» → живий запит у блоці коду → «Скопіювати запит» (тост «Запит скопійовано…»).
  Запит (мовою інтерфейсу) містить імʼя й теку простору, АБСОЛЮТНИЙ шлях до `docs/modules/authoring.md` цієї
  установки Deai і заборону довіряти самому. Шлях дає сервер (див. API).

### 4. AGENTS.md

- Файл `AGENTS.md` у теці простору. Блок між `<!-- deai:begin ... -->` і `<!-- deai:end -->` генерує Deai з шаблону;
  усе поза блоком — «Ваше», Deai його не чіпає.
- Шаблон — англійською, у репо (`app/templates/agents.md`). **Блок не залежить від компʼютера**: тека простору спільна
  через git, тож у блоці НЕМА абсолютних шляхів, імені користувача, імені простору (воно може бути різним у колег) —
  інакше в кожного свій «новіший» блок і нескінченні коміти туди-сюди. Шляхи установки — через позначку `<deai>`
  («тека вашої установки Deai Canvas»), яку агент дізнається з `GET http://127.0.0.1:8765/api/agents-md` (`paths.deai`) або
  з Налаштувань; адреса канваса — «типово http://127.0.0.1:8765». Розділи: Tasks and iterations · Comments
  (`python3 <deai>/bin/inbox.py --task <id>`, `… resolve <id> --reason "…"`) · Modules (API: `GET /api/modules?space=`,
  `POST /api/module-enable` / `module-settings` / `module-check` / `module-disable`; свої — у `modules/<id>/` за
  authoring.md; довіряє лише людина) · Settings (шестерня) · Never (секрети в теці, ручна правка `space.json`,
  правка старої ітерації). Кожна команда/ендпоінт у шаблоні мусить існувати — тест звіряє.
- Маркер begin несе версію Deai: `<!-- deai:begin v0.31.0 · generated by Deai Canvas; edit outside this block -->`.
- **Застарілий** = версія у маркері файла СТАРША за поточну Deai (порівняння semver) І текст блоку ≠ щойно згенерований
  (без рядка маркера). Незмінний шаблон не турбує. Файл із НОВІШОЇ версії Deai (колега оновився раніше) — не застарілий
  і не «понижується»: плашка «Цей блок записав новіший Deai ({v файла}) — оновіть Deai.», кнопка «Оновити з шаблону»
  неактивна.
- Розділ у Налаштуваннях: заголовок «AGENTS.md», праворуч «Скопіювати» і «Оновити з шаблону» (активна лише коли
  застарілий); над файлом, коли застарілий, — бурштинова плашка «Шаблон Deai {v} новіший за цей файл ({v файла}).» з
  кнопкою «Оновити з шаблону». Переглядач: шлях файла (моно) + копіювати шлях; дві частини з лівою колонкою
  «З шаблону · Deai {v}» / «Ваше · не чіпається».
- Файла нема → «AGENTS.md ще нема» + «Створити» (пише блок, «Ваше» порожнє).
- Файл є, маркерів нема → «Оновити з шаблону» вставляє блок НАГОРУ, весь наявний текст лишається нижче як «Ваше».
- Запис атомарний (тимчасовий файл у тій самій теці + `os.replace`), кодування UTF-8, перевод рядка `\n`.
- Новий простір (майстер) створює AGENTS.md одразу. Наявні простори — лише кнопкою (жодних тихих записів у чужі теки).
- Простір без теки (неявний) — розділ показує «У цього простору нема теки», без кнопок.

### 5. Простір

- «Назва» — поле; зберігається на Enter/blur (`POST /api/space-update {id,name,color}`, як діалог «Назва й колір…»).
- «Колір простору» — 6 плиток-мініатюр (наявні `space-1…6`, назви з `spaceColorName`), вибір застосовується одразу.
- **Колір простору фарбує все вікно**: поверхні `--s0…--s4`, `--line`, `--line2`, `--g950`(якщо є), тексти `--hi/--mid/
  --dim/--lo`, `--sel*` — в `oklch(L C var(--sp-h))`, де `--sp-h/--sp-c` задає `:root[data-space-color="space-N"]`
  (відтінки ті самі, що в `--space-N`). Для `space-1` (зелений, типовий) результат ≈ теперішні hex (ΔE мала — тест
  звіряє з допуском). Акценти стану (`--ok/--bad/--open`) не фарбуються.
- «Тека» — шлях моно + «Скопіювати шлях». (Відкрити у Finder — ні: ендпоінта нема.)
- Діалог «Назва й колір…» з фішки простору лишається.

### 6. Застосунок

- **Загальне**: «Мова інтерфейсу» — перемикач «Українська | English» (той самий `setLang`, що ⌘K); «Окреме вікно» —
  «Встановити» (`pwainstall`, лише коли `canInstall()`), «Встановлено» (`isStandalone()`), інакше рядок не показуємо.
- **Оновлення**: «Deai Canvas {current}», рядок стану (наявні `upSt_*`, «остання перевірка …»), «Перевірити зараз»
  (`/api/update-check`); є оновлення → «Оновити до {v}» відкриває наявний діалог оновлення (там «Що нового»).
- **Гарячі клавіші**: ті самі рядки, що аркуш `?` — дані виносимо в один масив, аркуш і розділ малюють із нього.

## API (нове)

- `GET /api/agents-md?space=<id>` → `{path, exists, hasBlock, outdated, newer, version, fileVersion, block, own,
  paths: {deai, inbox, authoring}}` (`paths` — абсолютні шляхи ЦІЄЇ установки, лише у відповіді, ніколи у файлі).
- `POST /api/agents-md {space}` → створює/оновлює блок; відповідь — те саме, що GET. Origin/машинні маршрути — як
  в інших POST.
- `GET /api/modules?space=` додає `deai: {authoring: <abs path>}` (для запиту «Свій модуль»).
- `POST /api/space-tool {space, tool: "figma", enabled}` → пише `tools` у `space.json`; `GET /api/modules` віддає `tools`.

## Тести (мінімум)

- Python: генерація блоку; блок однаковий на двох «компʼютерах» (різні `DEAI_HOME`/тека установки/імʼя простору →
  байт-у-байт той самий текст, без `/Users/`, `/home/`, `C:\\`); файл із новішої версії → `newer`, не `outdated`, `write`
  відмовляє; оновлення зберігає «Ваше» байт-у-байт; файл без маркерів; порожній/нема файла; атомарність
  (помилка запису не псує файл); `outdated` за вмістом; кожна команда/ендпоінт шаблону існує (`bin/inbox.py` має
  `resolve`, `--task`; маршрути є в serve.py); `space-tool` пише/читає; неявний простір.
- JS юніт: модель розділів; стан → дія картки (таблиця вище); каталог (зайнята роль → «Замінити»); запит «Свій модуль»;
  масив клавіш = аркуш `?`; CSS-страж: токени поверхонь — oklch від `--sp-h`; `space-1` ≈ старі hex.
- Живі: навігація й памʼять розділу; вимкнення питанням у картці; каталог → шухляда → картка; «Свій модуль» копіює;
  довіра з картки відкриває діалог; «В Figma» вимкнено → кнопки нема в смузі; колір простору міняє фон смуги;
  AGENTS.md створити/оновити зберігає «Ваше»; Мова; Оновлення «Перевірити зараз».
