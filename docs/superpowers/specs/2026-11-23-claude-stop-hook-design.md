# «Підключити» ставить Stop-хук Claude Code — правки AI в історії без скіла власника

Дата: 23.11.2026. Окремий реліз ПІСЛЯ 0.37.0 (гайд агента); версія — наступна вільна мінорна на момент злиття.

## Навіщо

0.36.0 (фаза «И») комітить правки AI окремо: `POST /api/autosync` спершу фіксує кожну СВОЮ брудну ітерацію задачі як
`itN: зміни AI` з трейлером `Deai-Actor: ai` (лише `iterations/<it>/`, без пушу, і з вимкненим autosync). Але сам Deai жодного
хука не ставить: `/api/autosync` кличе лише Stop-хук скіла dev-pipeline власника. Codex, інші AI й зовнішні користувачі Deai
лишаються без цього — їхні правки потрапляють у наступний коміт дії дизайнера, під його іменем і темою тієї дії. Інструкція в
AGENTS.md («після правок ітерації клич `/api/autosync`») — запасний шлях, на який агент може не зважити.

Мета: кнопка «Підключити» в «Налаштування → AGENTS.md» (рядок «Claude Code») ставить ще й Stop-хук Claude Code, що після кожної
відповіді кличе `/api/autosync` — правки Claude стають «AI» в історії без скіла власника.

## Рішення власника (23.11.2026)

- «Ок, хук через «Підключити» — давай, делай» (передано сесією «Deai Canvas»); «Отдельным релизом».
- Охоплення — лише ця машина: `.claude/settings.local.json` теки простору (не командний `settings.json`, не глобальний
  `~/.claude/settings.json`).
- Які задачі: УСІ задачі простору — свої брудні ітерації кожної фіксуються як AI (паралельні сесії на різних задачах покриті).
  Ризик прийнято: ручна правка дизайнера поза канвасом у ту саму хвилину теж стане «AI».
- Інтерфейс — один рядок «Claude Code»: «Підключити» ставить усе, чого бракує (CLAUDE.md і хук).
- Механізм — `curl` у налаштуваннях: хук пересилає канвасу JSON, який Claude Code сам дає хуку; сервер знаходить простір за `cwd`.
- Частини дизайну 1–4 — «ОК»; прототип рядка (6 станів) — «ОК».

## 1. Хук і потік даних

Запис у `hooks.Stop` файла `<простір>/.claude/settings.local.json` — ОДНА наша група:

```json
{"hooks": [{"type": "command", "timeout": 10,
  "command": "curl -s --noproxy '*' --max-time 5 -o /dev/null -X POST -H 'Content-Type: application/json' --data-binary @- http://127.0.0.1:<port>/api/autosync || true # deai-autosync"}]}
```

- `<port>` — порт канваса в момент підключення (`self.server.server_port`).
- Мітка `# deai-autosync` наприкінці команди — за нею наш хук відрізняється від чужих. Інших ознак немає.
- Хук завжди тихий: без виводу (`-o /dev/null`, `-s`), `|| true`, канвас вимкнено → нічого. Він ніколи не блокує й не валить
  відповідь Claude (`stop_hook_active` нам байдужий: ми не блокуємо).
- Claude Code перечитує файли налаштувань на льоту: хук діє й у вже відкритих сесіях.
- Windows на справжній машині не перевірено (команда — синтаксис sh).

`POST /api/autosync` отримує режим «за шляхом»:

| Запит | Поведінка |
|---|---|
| Є `X-Canvas-Task` чи префікс `/t/<task-id>` | Як зараз (0.36.0): задача запиту. Хук dev-pipeline й інструкція AGENTS.md не змінюються. |
| Нема задачі в запиті, у тілі абсолютний `cwd` (рядок) | Простір — найдовший префікс серед зареєстрованих (`agent_guide.find_space(path=cwd)`, неявні пропускаються). Для КОЖНОЇ задачі простору з `.git` — `ai_commit(task)` (збій однієї — рядок у stderr, решта йде). Далі — крок відправки, як зараз, для ПОТОЧНОЇ задачі цього простору (лише коли в модулі ввімкнено autosync). |
| `cwd` поза будь-яким простором | `200 {"ok": true, "changed": false, "reason": "no-space", "ai": null}`, нічого не робимо. |
| Нема ні задачі в запиті, ні `cwd` | Як зараз: поточна задача машини. |

- Відповідь у режимі «за шляхом»: поля кроку відправки поточної задачі (як зараз), `ai` — результат `ai_commit` поточної задачі
  (сумісність), `ai_tasks` — `{<task-id>: {it, sha, its}}` усіх задач, де щось закомічено (порожній обʼєкт — нічого).
- З тіла сервер бере ЛИШЕ `cwd`; решту (зокрема текст останньої відповіді Claude, `session_id`) не читає й нікуди не пише. Запит
  не виходить за межі машини.
- Тіло `/api/autosync` ≤ 2 МіБ (`AUTOSYNC_BODY_MAX`; більше — 413 ДО читання, як `local-shots`); хук на 413 мовчить, наступна
  відповідь закомітить.
- Подвійний виклик (наш хук + хук dev-pipeline після тієї самої відповіді) безпечний: другий застає чисті ітерації.
- Origin: та сама перевірка, що для всіх POST (curl Origin не шле — проходить; чужа сторінка — 403).

## 2. Запис хука — `app/claude_hook.py`

Окремий модуль (не роздуваємо `agents_md`):

- `command(port)` → рядок команди; `HOOK_MARK = '# deai-autosync'`; `FILE = '.claude/settings.local.json'`.
- `status(space_dir, port)` → `{state, path}`; ніколи не кидає.
- `connect(space_dir, port)` → `status` після запису; `disconnect(space_dir)` → `status` після.

Правила:
- Злиття, не перезапис: читаємо JSON, додаємо в `hooks.Stop` одну нашу групу; інші ключі й чужі хуки не чіпаємо. Наші групи
  (будь-який запис групи з `HOOK_MARK` у `command`) прибираємо й ставимо одну свіжу — повторне «Підключити» не дублює;
  стан `ok` → запису нема.
- Не чіпаємо взагалі (стан `unreadable`): симлінк чи не-звичайний файл (файл або тека `.claude`), не UTF-8, не JSON, верхній рівень
  не обʼєкт, `hooks` не обʼєкт, `hooks.Stop` не список.
- Запис атомарний: тимчасовий файл у `.claude/`, `fsync`, права як у наявного (новий — за umask), повторне читання перед
  `os.replace` (інакше `ValueError('changed')`). Відступ 2 пробіли, `ensure_ascii=False`: форматування цього файла може змінитись.
- Нема `.claude/` — створюємо.
- «Відключити»: прибираємо наші групи; порожні `Stop` і `hooks`, що спорожніли через нас, — теж; файл, що став `{}`, видаляємо.
- Поза git: тека простору — корінь репозиторію (`.git` — тека) → коли МИ створюємо файл, дописуємо `/.claude/settings.local.json`
  у `.git/info/exclude` (раз; локально, спільний `.gitignore` не чіпаємо). `.git` — файл (worktree, submodule) → exclude не пишемо.

Стани (`status`):
- `ok` — наш хук стоїть із командою для поточного порту;
- `missing` — нашого хука нема (файла нема, чи він без нашої групи);
- `stale` — наш хук є, але команда інша (порт, стара команда);
- `unreadable` — див. вище;
- `elsewhere` — тека простору всередині ІНШОГО git-репозиторію (`.git` є в предку, а не в самій теці; предок — не домашня тека):
  Claude Code тоді читає `settings.local.json` з кореня того репозиторію, а туди ми не пишемо. На Windows цього стану нема (там
  файл завжди поруч із `.claude/settings.json`).

## 3. API й рядок «Claude Code»

- `GET /api/agents-md?space=` → новий ключ `hook: {state, path}` (абсолютний шлях — лише у відповіді).
- `POST /api/agents-md {space, claude: true}` → `agents_md.claude_connect` + `claude_hook.connect`, коли стан хука `missing` чи
  `stale` (для `elsewhere`/`unreadable` хук пропускаємо, CLAUDE.md однаково підключаємо). Збій хука після успішного CLAUDE.md —
  відповідь зі станами обох (клієнт показує тост збою); `changed` → 409, `unreadable` → 503, як зараз.
- `POST /api/agents-md {space, hook: false}` → `claude_hook.disconnect`.
- Автооновлення при старті канваса хука НЕ чіпає (не ставить, не лагодить порт, не знімає): це налаштування людини.

Рядок «Claude Code» (`setup-model.js` `claudeRow(claude, hook)`, `first-run.js` `agentRowsHTML`) — як у прототипі, без пояснювальних
підписів; список того, що буде записано, — і є згода:

1. CLAUDE.md не підключено (`missing`/`no-import`) — ⚠, список: `CLAUDE.md — рядок @AGENTS.md`; плюс пункт хука, коли хук
   `missing`/`stale`; кнопка «Підключити».
2. CLAUDE.md `ok`, хук `missing` — ⚠, список з одного пункту хука; «Підключити».
3. Обидва `ok` — ✓ «Читає AGENTS.md; його правки в історії — як AI.»; «Відключити» (знімає лише хук).
4. Хук `stale` (CLAUDE.md `ok`) — ⚠ «Хук веде на інший порт канваса.»; «Оновити».
5. Хук `elsewhere` (CLAUDE.md `ok`) — ⚠ «Читає AGENTS.md. Хук тут не діє: тека простору всередині іншого git-репозиторію.»; без
   кнопки.
6. Хук `unreadable` (CLAUDE.md `ok`) — ⚠ «`.claude/settings.local.json` не читається (симлінк, тека чи не JSON).»; без кнопки.
- CLAUDE.md `unreadable` — як зараз (`frClaudeUnreadable`, без кнопки).
- Старий сервер без ключа `hook` — як зараз.
- Пункт хука в списку: `.claude/settings.local.json — правки Claude в історії як AI, лише на цьому компʼютері`.
- Тексти — `app/i18n.js` (uk і en), тости: підключено / відключено / не вдалося.

## 4. Документи для агентів

- `docs/agents/hooks.md`: хук від «Підключити» (що робить, де лежить, мітка) і режим `/api/autosync` за `cwd` (`no-space`,
  `ai_tasks`).
- `SETUP.md` («Agent status»): Stop-хук ставить канвас («Налаштування → AGENTS.md», «Підключити»); рецепт `SessionStart` лишається.
- Каркас AGENTS.md не змінюється: рядок про `POST /api/autosync` — запасний шлях для агентів без хука.

## Не робимо

- Командний `.claude/settings.json`, глобальний `~/.claude/settings.json`, запис у корінь батьківського репозиторію.
- Хуки Codex та інших агентів (для них — інструкція AGENTS.md).
- Автоматичне встановлення чи оновлення хука при старті канваса.
- Використання `session_id`, тексту відповіді чи транскрипту.

Відоме обмеження: Claude Code, запущений усередині теки задачі (вона — окремий git-репозиторій), читає
`settings.local.json` з кореня ТОГО репозиторію й хука простору не бачить. Звичайний запуск — у теці простору («Запуск агента»).
`--noproxy '*'`: змінна `http_proxy` в оточенні не відправить запит на `127.0.0.1` через проксі.

## Тести (повна строгість — пишемо в налаштування людини)

- `claude_hook`: нема файла; порожній `{}`; чужі хуки й інші ключі (байт-у-байт за змістом лишаються); наш хук зі старим портом
  (`stale` → переписано); повторне підключення (без запису); битий JSON, не обʼєкт, `hooks.Stop` не список, симлінк файла й теки
  `.claude` (`unreadable`, нічого не записано); зміна під час запису (`changed`); «Відключити» з чужими хуками й до `{}` (файл
  видалено); `.git/info/exclude` — рядок додано один раз, `.git`-файл — не чіпаємо; `elsewhere` (предок з `.git`, домашня тека — ні).
- `/api/autosync`: простір за `cwd`; AI-коміти в кількох задачах простору (`ai_tasks`); заголовок задачі важить більше за `cwd`;
  `no-space`; без `cwd` — як було; 413 понад `AUTOSYNC_BODY_MAX`; текст відповіді Claude у тілі не потрапляє в stderr.
- Наскрізно: справжня команда хука через `sh` з підробленим JSON сесії (stdin) проти тестового сервера на порту 0 → брудна
  ітерація стає `itN: зміни AI`; канвас вимкнено → тиша й код 0.
- `setup-model`: `claudeRow` для всіх 6 станів + CLAUDE.md `unreadable` + старий сервер.
- Живий тест рядка (під замком, один файл): «Підключити» → ✓ → «Відключити» → кнопка знову.
- Сторож покриття гайда: нових маршрутів нема; тексти тем звірені з кодом.
